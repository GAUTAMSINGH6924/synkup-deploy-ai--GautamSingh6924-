# Project Owner and Problem Validation

## Project Owner
- Role: Class Representative (CR)
- Institution: Panjab University, Chandigarh
- Agreed to test the application: Yes

## Problem Statement

Students frequently approach the Class Representative with questions regarding university-related information. To answer these questions, the CR manually searches the university website and relevant PDF documents.

This creates a recurring information retrieval task.

## Current Workflow

1. A student asks the CR a university-related question.
2. The CR searches the university website.
3. The CR locates relevant notices or PDF documents.
4. The CR reads the available information.
5. The CR communicates the answer to the student.

## Proposed Solution

Develop a Retrieval-Augmented Generation (RAG) based Campus AI Document Assistant that retrieves relevant information from university documents and generates answers supported by source citations.

## Expected Benefits

- Reduce manual document searching.
- Reduce the time required to answer recurring questions.
- Provide traceable source citations.
- Avoid unsupported answers when information is unavailable.
